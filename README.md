# 📊 InsightIQ

**Turn CSVs into conversations.**

InsightIQ is an AI-powered data analysis assistant that lets you upload a CSV or Excel file and instantly explore it — through auto-generated charts, an AI-written EDA summary, and natural-language Q&A (in English or Hinglish) powered by Google Gemini.

## ✨ Features

- **📁 Flexible Data Upload** — Supports CSV and Excel (`.xlsx`, `.xls`) files, single or two-file mode for joining/comparing datasets
- **🏠 Instant Overview** — Row/column counts, missing-value stats, auto-generated charts (distribution, top categories, trends over time)
- **🧠 AI-Powered Auto EDA** — One-click exploratory data analysis summary in plain English or Hinglish, highlighting data quality issues and patterns
- **💬 Ask AI (Conversational)** — Ask questions about your data in natural language; the AI writes and runs pandas/matplotlib code on the fly, with chat-style history and context memory across follow-up questions
- **🔁 Error Recovery** — If the AI generates faulty code, a one-click "Regenerate" option retries the analysis
- **🧹 Data Cleaning Tools** — Handle missing values, remove duplicates, drop/rename columns — all from the UI, with the option to use the cleaned dataset directly for analysis
- **⚖️ Compare Mode** — Upload two files and compare summary statistics and totals side by side, or join them on a common column
- **⬇️ Export Options** — Download cleaned data as CSV or generated charts as PNG
- **🌗 Light/Dark Theme** — Toggle between polished light and dark modes with a single click
- **🎨 Custom UI** — Gradient accents, animated splash screen, and a popup-style settings sidebar

## 🚀 Getting Started

### Prerequisites
- Python 3.10+
- A [Google Gemini API key](https://ai.google.dev/)

### Installation

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/insightiq.git
cd insightiq

# Create and activate a virtual environment
python -m venv venv
venv\Scripts\activate      # Windows
source venv/bin/activate   # macOS/Linux

# Install dependencies
pip install -r requirements.txt
```

### Configuration

Create a `.env` file in the project root:

```
GEMINI_API_KEY=your_api_key_here
```

### Run the app

```bash
streamlit run app.py
```

The app will open at `http://localhost:8501`.

## 🗺️ How It Works

1. **Upload** a CSV or Excel file
2. Get an **automatic EDA summary** generated by AI
3. **Ask questions** about your data in plain English or Hinglish — the AI writes and runs the analysis code for you
4. **Clean your data** with built-in tools when needed
5. **Download** your results — cleaned data or generated charts
